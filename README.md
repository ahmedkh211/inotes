# iNotes — مفكرة تعمل بدون إنترنت

مشغّل النوتات الحديث… بس إصدار "i" تاني 😄 تطبيق **iNotes** هو مفكرة عربية (RTL) تعمل **بالكامل دون اتصال بالإنترنت**، وبياناتك تفضل محفوظة على جهازك.

بُني بـ HTML/CSS/JS نقي بدون أي مكتبات أو أدوات بناء — أي ملف تشغيل، وهكذا شغالة الترقية.

## الميزات
- **كتابة غنية**: تنسيق عريض/مائل/تسطير/مشطوب، قوائم نقطية، ألوان نص وتظليل، 3 خطوط عربية، 3 أحجام.
- **كتابة بخط الإيد**: لوحة رسم بألوان قلم متنوعة وسماكات مختلفة + ممحاة + تراجع.
- **نوتات صوتية**: سجّل صوتك من الميكروفون وسيبها جوه النوتة وشغّلها لاحقاً حتى من غير نت.
- **إزالة المرفقات**: زر ✕ فوق كل صورة أو تسجيل صوتي بيحذفه من النوتة فوراً.
- **زر «+ نوتة جديدة»**: واضح في الهيدر على الشاشات الكبيرة + زر عائم شرّيّت على الموبايل والتابلت.
- **إيموجي**: لوحة إيموجي مدمجة لأصناف مختلفة (وشوش، إيدين، قلوب، حيوانات، طعام، وأشياء).
- **تصدير**: كل نوتة ممكن تصديرها **صورة PNG** أو **ملف PDF** أو **ملف نصي TXT**.
- **الواجهة الخارجية (الداشبورد)**: كروت ملونة تبدأ فارغة وتتعبى، ترتيب بـ"تثبيت" النوتات المهم أول، بحث فوري بالعنوان أو المحتوى.
- **أنيميشن هادي**: ظهور الكروت بالتتابع، انزلاق المحرر من قاع، زر عائم يتحرك بسلاسة.
- **وضع داكن + فاتح** محفوظ، **الإعدادات**: خط/حجم/لون افتراضي، أنيميشن on/off، نسخ احتياطية JSON كاملة.
- **أوفلاين 100%**: Service Worker كاش كامل، يبتحدث من غير نت.

## طريقة تشغيله على جهازك محلياً (اختياري)

```bash
cd inotes
python dev/server.py 8091 .
```
افتح `http://127.0.0.1:8091/?nosew` للتطوير بدون Service Worker بسرعة — أو عندك النسخة النهائية بدون `?nosew` للتجربة على الأوفلاين والتثبيت.

## النشر أو التحديث على جوجل
يوجد نسخة مباشرة من iNotes مشتركة الدومين مع iMusic على GitHub Pages:
- **الرابط**: https://ahmedkh211.github.io/inotes/

لو عملت تعديل - للنشر:
1. عدّل `VERSION` في `sw.js` (مثال: `'inotes-v1.0.1'`) لتنزيل نسخة جديدة تلقائياً على الأجهزة المثبتة.
2. ارفع الملفات إلى مستودع `GitHub`.

## تثبيت التطبيق على التابلت / الموبايل (أندرويد)
1. افتح الرابط في Chrome.
2. اضغط زر **«تثبيت التطبيق»** أعلى الصفحة (أو من قائمة Chrome ⋮ → «تثبيت التطبيق»).
3. هيظهر أيقونة iNotes على الشاشة الرئيسية، ويفتح ملء الشاشة من غير شريط المتصفح.

## ملاحظة مهمة للخصوصية
- بياناتك (النوتات والصوت والرسم) **مش بتغادر الجهاز أبداً** — بامتداد IndexedDB والذكرة الداخلية.
- عشان تعمل نسخ احتياطية (أو تستوردها لجهاز مختلف)، استخدم زر **«تصدير نسخة»** من الإعدادات أو **«استيراد نسخة»**.
- ⚠️ متمسحش بيانات الموقع من إعدادات Chrome نصياً (`Edge → محو بيانات التصفح`): هيكمش النوتات المخزنة.
